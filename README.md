# GelikRooms Admin v5.0 | Premium Web + Mobile + ЮKassa

Премиальная адаптивная панель управления апартаментами: 14 разделов, единая дизайн-система, функциональные демонстрационные сценарии, мобильная навигация и PWA.

**Важно:** версия 5.0 представляет собой самостоятельный интерактивный фронтенд-прототип. Это не действующая CRM сайта gelikrooms.ru. Вся информация, включая брони, телефоны, доходы, апартаменты и имена гостей, демонстрационная. Данные по объектам и бронированиям сохраняются в `localStorage` текущего браузера; фотографии сохраняются в IndexedDB. Данные не синхронизируются между устройствами. Локальные демоплатежи, сообщения и бронирования никуда не отправляются. В папке `server/` появился самостоятельный серверный адаптер ЮKassa для тестового подключения: без ваших реквизитов магазина и серверной базы бронирований реальные оплаты не включены.

## Запуск

Python 3, Node.js (только для тестов), любой современный браузер. Сборка и зависимости не нужны.

```bash
cd gelikrooms-admin
python3 -m http.server 5173
```

Откройте `http://localhost:5173`. На телефоне при публикации на HTTPS можно установить интерфейс на главный экран как PWA. Для офлайн-режима кэшируется оболочка приложения; это не синхронизирует данные между устройствами. На iOS установка выполняется через «Поделиться» и «На экран Домой», при поддержке браузера.

### Даты, тарифы и финансы

Интервалы полуоткрытые: заезд входит в период, дата выезда не входит. Новый тариф переопределяет базовую цену комнаты на выбранные ночи. Существующая бронь не пересчитывается при изменении тарифов задним числом. Нельзя сохранить пересекающиеся активные брони, блокировки или тарифы одного объекта.

Оплаты и возвраты создают отдельные локальные записи. Поле оплаченной суммы в бронировании согласовано с журналом. Отчёты по загрузке считают занятые ночи в периоде, ADR - оценочную стоимость занятой ночи, RevPAR - стоимость на доступную ночь. Эти показатели используют демоданные, не являются финансовой отчётностью.

### Хранение

Локальные данные: ключ `gelikrooms-premium-admin-demo-v1`, сохранён для совместимости v1/v2/v3. Фотографии: IndexedDB `gelikrooms-premium-photo-gallery-v1`, object store `photos`. JSON-бэкапы версии `gelikrooms.demo.v4` включают все локальные фотографии в base64. Импорт v2 и v3 поддерживается с переносом предыдущих полей оплаченных сумм в отдельный локальный журнал. В импортируемых v3/v4 проверяются структуры, ссылки, суммы, даты и пересечения. В v4 дополнительно проверяются фото, их ID, размеры и обложки. Импорт v2/v3 очищает галерею текущего браузера после подтверждения.

Не используйте прототип для настоящих персональных данных. Для production нужны API, база данных, права доступа, логирование на сервере, защищённые сессии, транзакционная проверка дат, безопасная обработка оплаты и интеграция с каналами продаж.

## Тесты

```bash
node tests/smoke.cjs
node tests/advanced.cjs
```

Оба сценария пройдены 23 ноября 2026. Новые серверные тесты: `cd server && pytest -q test_app.py`. Проверка адаптивного интерфейса: `python tests/browser_v5.py`. Отдельный тест `python tests/browser_visual.py` проверяет интерфейс галереи в Chromium без сетевой навигации, используя адаптер IndexedDB в памяти для тестовой среды. Это настоящие скриншоты отрисованного браузером интерфейса, но тест с адаптером не является доказательством реальной IndexedDB-персистентности при перезапуске браузера. Тест визуально проверяет загрузку, редактирование подписи, замену, обложку, сортировку, просмотр, удаление, export/import JSON и адаптивную мобильную версию.

## Работа с фотографиями, полный пользовательский цикл

1. В разделе «Апартаменты» откройте «Управлять галереей». При создании объекта сохраните его, галерея откроется автоматически.
2. Нажмите на зону загрузки, выберите сразу несколько снимков с телефона или компьютера. На web можно перетащить файлы в зону загрузки.
3. Приложение декодирует файлы, проверяет формат и лимит 15 МБ, ограничивает исходный размер 65 Мп, уменьшает большую сторону до 2200 px, сохраняет JPEG с качеством 84% без EXIF-метаданных. Поддерживается JPG/PNG/WebP/AVIF; HEIC/HEIF только если браузер способен декодировать файлы.
4. На карточке фото нажмите звезду, чтобы сделать обложкой. Переставляйте стрелками (также доступно перетаскивание на компьютере); порядок сохраняется. Можно изменить подпись или заменить файл, не изменяя позицию и статус главного фото.
5. Нажмите на превью для полноэкранного просмотра, используйте стрелки и Escape на компьютере. Удаление требует подтверждения и очищает объект из IndexedDB. Если удалена обложка, первой фотографией автоматически станет следующая.
6. В «Настройках» экспортируйте JSON с фото для переноса между браузерами и импортируйте его в другом браузере. Импорт заменяет весь демонабор данных, включая фотографии, после подтверждения. Пример находится в `previews/v4/sample-gallery-backup.json`.

**Ограничения:** 30 фото на объект; загрузка и удаление пока только в текущем браузере. Фотографии НЕ загружаются в gelikrooms.ru и не доступны другим сотрудникам. При очистке данных сайта без бэкапа изображения теряются. Для публикации нужен серверный API, авторизация и объектное хранилище. Проект API описан в `docs/PHOTO_WORKFLOW.md`.

## Подключение ЮKassa и мобильный интерфейс

Раздел «ЮKassa» подключается к отдельному backend по `/api`. При тестировании без ключей он показывает отключённое состояние и не имитирует успешную оплату. Фискальный чек, подтверждение платежа, возврат и webhook реализованы в серверном адаптере; для production нужны учётные данные магазина, настройки кассы, реальная БД бронирований, авторизация и HTTPS. Подробности в `docs/YOOKASSA_INTEGRATION.md`.

На телефоне реализован интерфейс в нативном стиле, который можно установить как PWA. Это не готовый SwiftUI/Kotlin пакет. Подробнее в `docs/NATIVE_UX.md`.
