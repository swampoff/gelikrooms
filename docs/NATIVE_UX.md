# GelikRooms Native UX, v5

Статус: адаптивный браузерный интерфейс и PWA, а **не нативное приложение на SwiftUI/Kotlin**.

Мобильная версия следует знакомым жестам и паттернам мобильных ОС:

- постоянная нижняя навигация (Обзор, Брони, Календарь, Номера, Ещё), включая safe-area;
- кнопка новой брони показана только в контекстных разделах;
- «Ещё» открывает выезжающую снизу панель всех 14 разделов;
- формы и детали брони открываются как bottom sheet;
- закрытие свайпом вниз с заголовка панели;
- размер интерактивных элементов 42-56 px и увеличенный текст, поля 16 px против автоматического масштабирования iOS;
- более читаемые карточки, адаптивные KPI, финансовые записи, таблицы заменены на карточки на телефоне;
- экран ЮKassa содержит статус подключения, серверные операции и последовательность действий. Нет фиктивного подтверждения оплаты;
- приложение устанавливается через PWA при размещении на HTTPS с service worker. Для синхронизации, background push и реальных операций нужен backend.

Тесты браузера: `python tests/browser_v5.py`. В текущей среде предпросмотр отрисован в Chromium через document harness из исходников (без сетевой навигации). Он проверяет `#yookassa`, модальное окно подключения, мобильное меню, бронирования, апартаменты, отсутствие переполнения на телефоне и ошибки JS. Это не тест мобильных Safari и Chrome на физических устройствах.

Если нужны **настоящие нативные приложения**, следующий этап: SwiftUI (iOS) и Kotlin/Jetpack Compose (Android), общий авторизованный API, push-уведомления, фото с камеры, безопасные сессии. PWA сама по себе не является нативным приложением.
